# CEM downloads

Everything CEM gives away to download or install that is not the design system: scripts, Claude Code hooks, plugins,
templates, spreadsheets, checklists and prompt packs.

- One folder per item. Each folder has its own README, licence and version.
- Every item here is cleaned: no names, paths or keys.
- Each item's page is on [Tools](https://tools.cemresearchproject.org).
- Calculators are in [cem-ui](https://github.com/cemresearchproject/cem-ui); the MCP server is
  [cem-mcp](https://github.com/cemresearchproject/cem-mcp).

Part of the [CEM Research Project](https://cemresearchproject.org). Released under the MIT licence (`LICENSE`).
